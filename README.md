# UUI Study Resources (proposal)

A proposed Resources section for Urantia University Institute.

- `index.html` — home with nine resource cards
- `book/` — The Urantia Book Online (text in `book.js`, built by `tools/build_book.py`; page by `tools/make_reader.py`)
- `glossary/` — glossary A–Z (built by `tools/make_glossary.py` from English_Master_Glossary.xlsx)

Hosted on Cloudflare Workers (static assets); pushing to GitHub deploys.
